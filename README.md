# RichRock Designers & Printers Website

Professional website for RichRock Designers & Printers.

## What's Included

- **Home** (`index.html`) – Hero, services overview, why choose us, CTAs
- **About** (`about.html`) – Company story, mission & vision
- **Services** (`services.html`) – Detailed service descriptions
- **Portfolio** (`portfolio.html`) – Placeholder ready for your work samples
- **Contact** (`contact.html`) – Contact form + WhatsApp + social links

## Features

- Fully responsive (mobile, tablet, desktop)
- Professional design using your brand colours and logo
- Floating WhatsApp button on every page
- Easy to edit (plain HTML + Tailwind CSS via CDN)
- Lead-generation focused

## How to View Locally

1. Open the folder `richrock-website`
2. Double-click `index.html` to open in your browser  
   **or** use a simple local server if you prefer.

## How to Edit Content

All pages are regular HTML files. You can open them in any text editor (VS Code, Notepad, etc.) and change:

- Text content
- Phone number / WhatsApp link
- Social media links
- Add your own project photos to the Portfolio page later

The styling uses **Tailwind CSS** loaded from a CDN, so you don’t need to install anything.

## How to Make the Contact Form Work

1. Go to [formspree.io](https://formspree.io) and create a free account
2. Create a new form
3. Copy the form endpoint (looks like `https://formspree.io/f/xxxxxxxx`)
4. In `contact.html`, replace `YOUR_FORM_ID` with your actual form ID

## How to Host Online (Free Options)

### Option 1: Netlify (Recommended – easiest)
1. Go to [netlify.com](https://www.netlify.com) and sign up
2. Drag and drop the entire `richrock-website` folder onto the Netlify dashboard
3. Your site will be live in seconds with a free `*.netlify.app` address
4. Later you can connect a custom domain (e.g. `richrockdesigners.co.ke`)

### Option 2: Vercel
1. Go to [vercel.com](https://vercel.com)
2. Import the folder or connect a GitHub repo
3. Deploy

### Option 3: GitHub Pages
1. Create a GitHub repository
2. Upload the files
3. Enable GitHub Pages in the repo settings
